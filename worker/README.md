# Сповіщення через Cloudflare Worker — налаштування (15 хвилин, безкоштовно)

Один маленький безкоштовний посередник відповідає одразу за два сповіщення
про кожне замовлення:

- **фірмовий лист покупцю** (через Resend);
- **повідомлення вам у Telegram**.

Обидва ключі — ключ Resend і токен Telegram-бота — лежать усередині воркера.
У код сайту й у базу вони не потрапляють, тому вкрасти їх із браузера
неможливо. Воркер приймає лише дані замовлення й сам збирає і лист, і текст
повідомлення — надіслати через нього щось стороннє не вийде.

---

## 1. Підтвердити домен у Resend

Щоб листи йшли з адреси `@reyter.men`, а не в спам:

1. [resend.com](https://resend.com) → **Domains** → **Add Domain** → `reyter.men`
2. Resend покаже DNS-записи (TXT і MX). Додайте їх там, де керуєте
   доменом reyter.men.
3. Дочекайтесь статусу **Verified** (зазвичай 5–30 хвилин).

> Поки домен не підтверджено, Resend дозволяє надсилати листи **лише на
> вашу власну пошту** — цього досить, щоб протестувати, але не для клієнтів.

## 2. Створити ключ Resend

Resend → **API Keys** → **Create API Key** → права **Sending access**.
Скопіюйте ключ (показується один раз).

> Якщо ключ колись світився в переписці чи скріншоті — створіть новий,
> а старий видаліть. Ключ дає право надсилати листи від вашого домену.

## 3. Створити Telegram-бота

1. Напишіть у Telegram боту **@BotFather** → `/newbot` → скопіюйте токен
   вигляду `1234567890:AA...`
2. Відкрийте свого нового бота і натисніть **Start** (без цього він не
   зможе вам написати).
3. Якщо сповіщення має бачити вся команда — створіть групу, додайте туди
   бота і напишіть у ній будь-що.

Chat ID підкаже сама адмінка після кроку 5 — кнопка **«Показати Chat ID»**.

## 4. Створити Worker

1. [dash.cloudflare.com](https://dash.cloudflare.com) → зареєструйтесь (безкоштовно)
2. **Workers & Pages** → **Create** → **Start with Hello World** → **Deploy**
3. Відкрийте створений воркер → **Edit code**
4. Видаліть увесь код і вставте вміст файлу [`worker.js`](worker.js) → **Deploy**

## 5. Додати змінні

У воркері: **Settings** → **Variables and Secrets** → **Add**:

| Назва | Тип | Значення |
|---|---|---|
| `RESEND_KEY` | Secret | ключ із кроку 2 |
| `MAIL_FROM` | Text | `REYTER <orders@reyter.men>` |
| `MAIL_BCC` | Text | `reyter.store1@gmail.com` — копія кожного листа вам |
| `TG_TOKEN` | Secret | токен бота з кроку 3 |
| `TG_CHAT` | Text | Chat ID отримувачів, кілька — через кому |
| `ALLOW_ORIGIN` | Text | `https://reyter.men` |
| `ADMIN_KEY` | Secret | *необовʼязково* — пароль для службових кнопок адмінки |
| `META_CAPI_TOKEN` | Secret | токен Meta Conversions API для Pixel `1564358352080564` |
| `META_TEST_EVENT_CODE` | Secret | *необовʼязково* — код із «Test events» лише на час перевірки |

Для серверної події `Purchase` Worker також має KV binding
`CAPI_PENDING`. У репозиторії він уже описаний у `wrangler.jsonc`;
окреме сховище зберігає контекст рахунку максимум сім днів і не
змішується з кешем сайту.

Токен Meta не вставляйте у `worker.js` або `wrangler.jsonc`. Його
треба додати як Secret у Cloudflare або через безпечний інтерактивний
виклик із цієї теки:

```bash
npx --prefix ../app wrangler secret put META_CAPI_TOKEN --config wrangler.jsonc
```

Після цього Worker відправляє `Purchase` з підписаного webhook
Monobank. Браузерний Pixel використовує той самий `event_id`, тому
Meta дедуплікує пару Browser + Server в одну покупку.

> ⚠️ Після додавання змінних обовʼязково натисніть **Deploy** — без
> цього воркер їх не побачить. Назви мають бути точно такі, без пробілів
> на початку чи в кінці значення.

> Поки домен не підтверджено (крок 1), у `MAIL_FROM` залиште
> `REYTER <onboarding@resend.dev>`, а тестові листи надсилайте
> лише на пошту, якою ви зареєструвались у Resend.

**`TG_CHAT` ще не знаєте?** Додайте поки решту змінних, натисніть **Deploy**,
далі перейдіть до кроку 6 і натисніть **«Показати Chat ID»** — адмінка
запитає Telegram і покаже готовий рядок, який лишиться вставити в цю
змінну (і ще раз **Deploy**).

**`ADMIN_KEY`** захищає службові кнопки адмінки («Перевірити», «Показати
Chat ID», «Надіслати тестове повідомлення») від сторонніх, які знають
адресу воркера. Придумайте будь-який довгий рядок і впишіть його
в адмінці — там він зберігається лише у вашому браузері.

### Як швидко перевірити воркер

Вставте адресу воркера в браузер. Має відповісти:

```json
{"ok":false,"error":"Method not allowed"}
```

Це нормально — воркер приймає лише POST.

## 6. Вписати адресу воркера в адмінку

Скопіюйте адресу воркера — вона виглядає як
`https://назва.ваш-акаунт.workers.dev`.

Адмінка → **Налаштування** → поле **Адреса Worker** → вставте →
**Зберегти налаштування**.

Далі, не виходячи звідси:

- **Перевірити** — покаже, які змінні воркер бачить (Resend, Telegram,
  скільки отримувачів);
- **Показати Chat ID** — знайде всіх, хто писав боту;
- **Надіслати тестове повідомлення** — перевірить Telegram;
- **Надіслати тест** (у розділі FormSubmit) — перевірить лист.

## 7. Прибрати старий токен із бази

Якщо ви налаштовували Telegram раніше — токен бота лишився в базі сайту
і його бачить будь-хто, хто відкриє сторінку. Адмінка покаже про це
попередження з кнопкою **«Прибрати токен із бази»**. Натисніть її після
того, як тестове повідомлення через воркер уже дійшло.

Разом із цим оновіть правила Firestore із файлу
[`../firestore.rules`](../firestore.rules): у новій версії налаштування
читає лише адміністратор, а покупцеві лишається публічний документ
`settings/public` з адресою воркера.

> Порядок важливий: спершу **збережіть налаштування в адмінці** (це
> створить `settings/public`), і лише потім вставляйте нові правила.

## Листи з персональними промокодами

Той самий воркер надсилає й листи з персональними промокодами —
кнопка **«Надіслати на пошту»** в адмінці (розділ «Промокоди»).
Лист має той самий фірмовий вигляд: логотип на синьому, великий
код у рамці, розмір знижки, умови та кнопка «Перейти до покупок».

## Що це дає

- Клієнт отримує фірмовий лист із логотипом REYTER на синьому тлі,
  номером замовлення, списком позицій, сумою та кнопкою «Відстежити замовлення»
- Лист приходить мовою, якою клієнт користувався на сайті
- Ви отримуєте в Telegram акуратне повідомлення з номером, контактами,
  доставкою, списком позицій, знижкою та сумою
- Копія кожного листа — на пошту магазину (`MAIL_BCC`)
- **Ключ Resend і токен бота ніколи не потрапляють у браузер**
- Воркер сам малює лист і сам збирає текст повідомлення, тому надіслати
  через нього сторонній лист чи довільне повідомлення неможливо

Безкоштовних лімітів вистачає з запасом: Cloudflare — 100 000 запитів на
день, Resend — 3 000 листів на місяць.

Якщо воркер не налаштований, сайт працює як раніше: клієнт отримує
простий текстовий лист через FormSubmit.
