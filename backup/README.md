# Резервна копія каталогу

`data.js` — знімок опублікованого каталогу: товари, залишки,
категорії й налаштування сайту. Адмінка перезаписує його після
кожної публікації через GitHub API (потрібен токен із дозволом
**Contents: Read and write** — його вводять у діалозі публікації).

**Навіщо.** Це єдина копія каталогу поза Firestore, і в неї є
історія: кожна публікація лишає окремий коміт, тож видно не лише
поточний стан, а й будь-який попередній. Якщо база колись
постраждає, звідси можна відновитись.

Файл писався для попереднього сайту — той читав його першим, поки
вантажилась база. Сайту більше немає (обидві старі версії
прибрано 15.08.2026), а копія лишилась: свою другу роботу вона
виконує й далі.

**Руками не правити.** Наступна публікація перезапише файл цілком.
Якщо треба змінити налаштування — їх джерело в
[`app/lib/site-config.ts`](../app/lib/site-config.ts).

**Невдача копіювання нічого не скасовує.** Публікація в базу вже
відбулась; адмінка просто напише, що резервний файл не оновлено, і
пояснить чому — найчастіше немає токена або в нього забракло прав.
