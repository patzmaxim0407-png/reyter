    Попередній перегляд

    Налаштування сповіщень

    Telegram — сповіщення вам про нові замовлення

    Напишіть у Telegram боту @BotFather → /newbot → скопіюйте токен. Потім відкрийте свого бота і натисніть Start.

    Напишіть боту @userinfobot — він відповість вашим Id. Сповіщення прийдуть у ваш чат із вашим ботом.

    Email покупцю — підтвердження замовлення (EmailJS)

    Зареєструйтесь на emailjs.com (безкоштовно до 200 листів/міс) → Add Service (Gmail) → Create Template. У шаблоні поле «To Email» = {{to_email}}, а в тексті можна використовувати: {{to_name}}, {{order_num}}, {{order_items}}, {{order_total}}, {{order_delivery}}.

    Резервна копія каталогу

    Поточний каталог із бази буде записано у файл new/js/data.js репозиторію patzmaxim0407-png/reyter. Сайт показує цей файл першим, поки завантажується база — оновлюйте копію після великих змін каталогу.

    Створіть токен: GitHub → Settings → Developer settings → Fine-grained tokens → доступ лише до репозиторію reyter, дозвіл Contents: Read and write. Токен зберігається тільки у вашому браузері.
